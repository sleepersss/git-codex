# 游戏下载归档助手 0.2.2（IDM）

沿用Edge的移动云盘登录状态：点击介绍页云盘链接 → 自动进入目录、勾选PC并点下载 → IDM静默下载 → 确认完成与落盘 → 关闭本任务云盘标签 → 校验解压 → 按类型/名称归档并保存介绍 → 验证成功后删除对应IDM源包。

IDM下载目录默认 `D:\8_Temporary files\IDM\programs`。兼容 `.exe` 自解压包及 `_2`、`_3` 重名后缀。插件不依赖Edge下载完成事件；会读取IDM完成记录，核对来源摘要、字节数和新文件，并约每30秒检查一次。请保持Edge运行。解压后的成员检查尺寸并记录SHA256。

更新后在 `edge://extensions` 重新加载扩展，允许新增移动云盘下载域名权限。在插件设置确认“IDM接管下载”、下载目录、“验证成功后删除本任务IDM源包”，检查助手版本为0.2.2。已注册的本地助手不需要重装。

失败、已有目标或介绍图片缺失时保留源包；只有成功发布游戏和验证完整后才删单个源包。不会清空IDM目录，也不会自动处理监视开始前已有的文件。对于现在已经下载的旧包，在原任务点“关联IDM下载”，核对文件路径、大小、时间后确认。

0.1.1 修正了云盘表格中隐藏名称节点导致无法进入目录/读取PC文件的问题。更新后到 `edge://extensions` 点此扩展的“重新加载”，刷新任务页后重试原失败任务即可。

0.1.2 改为勾选该PC文件左侧复选框，确认只选中该文件且“已选择1项”，再点击选中工具栏的专用下载按钮；不点击文件名打开预览。存在其他勾选或选中状态无法确认时停止。Edge如果显示“打开/另存为/保存”，此版本仍需用户点击“保存”；自动保存尚未验证。

## 安装

1. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”。
2. 选择“加载解压缩的扩展”，选中本项目的 `extension` 文件夹。
3. 打开插件“设置与助手安装”，复制插件 ID。
4. 双击项目中的 `安装本地助手.cmd`，粘贴 ID。只注册当前用户的 Edge 本地助手，不需要管理员权限。
5. 回到设置，填写归档根目录、你提供的解压密码、7-Zip 路径，并点“检查助手连接”。默认分类根为 `E:\1_Game\some games`。

助手使用本机已有 Python 与 7-Zip，路径可更改。不要移动项目文件夹；若移动请重新运行安装器。

## 使用

完成首次助手连接与设置后，在 Sway 介绍页直接点击移动云盘链接，就会接管该游戏的 PC 下载和归档。第一次建议按下面的“选择游戏”流程核对卡片、授权图片域名；相同图片域名后续无需重复授权。可在设置关闭自动接管。

1. 在 Edge 登录移动云盘。
2. 打开游戏介绍页，点插件 → “在当前网页选择游戏”。
3. 点击某个游戏的介绍正文。插件只接受包含一个【类型】标题和一个移动云盘链接的卡片。图片和正文应属于同一块 DOM；若网站把图片拆在另一结构，需要现场适配。
4. 再打开插件，检查游戏名称和图片数量，点“下载并归档”。首次需要允许该卡片图片域名的访问权限。
5. 插件在后台标签读取分享文件，勾选唯一PC包并点击选中工具栏下载，IDM接管。仅使用网页正常提供的下载流程。
6. IDM完成后，本地助手校验、解压，创建 `分类\游戏名\介绍`，保存 `验证记录.json`。全部验证成功后删除对应源包；图片失败会记录并保留源包。

常见分类是 RPG、SLG、ACT；“动态”保留在介绍中，不另建目录。兼容现有 ADV、GAL 分类。原包内层级保留在游戏名容器目录下。

## 任务与恢复

- 多个 PC 包：停止自动选择，防止下载错版本。
- 网页要求客户端/再次登录：任务页打开云盘标签处理，之后点“重试下载”。
- IDM下载关联：仅接管监视开始后新增的匹配文件，并与新增/变化的IDM完成记录、精确来源摘要、完成字节数一致。没有捕获来源或出现多个候选时不猜测；可手动关联该任务的IDM源包。已有文件即使后来更改时间戳也不会自动接管。
- 密码错误：修改密码后“重试解压归档”。
- 目标游戏目录已存在：拒绝覆盖；请在开始任务前改成含版本号的不同游戏名。失败临时目录保留供检查。
- 浏览器关闭：任务保留，未完成处理需要检查后重试。归档时保持 Edge 打开。
- 网页安全下载拦截由用户处理；插件不会绕过拦截或执行游戏程序。

## 验证范围

本地逻辑、DOM fixture、真实Native消息的IDM接管/归档/清理链路、实际隔离Edge加载均有验证。真实IDM完成字段已只读核实；当前账号的新下载仍需重新加载后现场联调。网站DOM与IDM字段变化时将停止自动关联。此版不支持百度/UC自动下载。

## 卸载

在 Edge 删除扩展，运行 `卸载本地助手.cmd` 移除当前用户注册。游戏与项目文件保留。
