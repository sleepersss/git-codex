归档设置

使用 Edge 登录状态触发IDM下载，完成后归档到“分类 / 游戏名”。

本地归档

常见分类：RPG、SLG、ACT。也支持已有 ADV、GAL 分类。

仅保存到此插件的本地存储，不写入介绍和任务日志。

在 Sway 介绍页生效。新图片域名需先用“选择游戏”授权一次，未授权图片会记录失败。

下载与源包清理

只删除对应的压缩包。旧包、失败任务及介绍图片缺失时保留。请保持Edge运行，约每30秒检查一次IDM完成状态。

连接本地助手

首次使用，在项目目录双击 安装本地助手.cmd，输入下面的插件 ID。

注册器只为当前 Windows 用户注册此助手。卸载时运行“卸载本地助手.cmd”。
