# Edge 游戏下载助手设计

目标：在已登录 Edge 中从游戏介绍页点击移动云盘链接，识别 PC 包、下载后自动解压到类型/游戏名目录，并保留介绍文字和图片。

选择：Manifest V3 插件 + Python Native Messaging 本地助手。纯插件无法操作任意归档目录或调用解压工具；本地 HTTP 服务需要常驻并开放端口，因此采用浏览器按需启动的本地助手。

插件：在介绍页开启一次“选择游戏”模式，点击对应介绍卡片，提取【类型】标题、文字、图片和移动云盘链接。仅针对用户登记的下载任务自动处理分享页；在后台标签使用现有登录状态打开分享目录。优先 PC/Windows，排除安卓/APK，若有多个 PC 候选则停止并提示。网页接口未知，第一版使用可见 DOM 点击下载，不承诺真正无标签接口直下；页面可后台打开，用户不用手动选文件。

下载关联：通过 webRequest 观察专用云盘标签发出的实际请求和跳转地址，仅在浏览器下载URL匹配该标签的观察记录、文件名匹配PC选择、时间在60秒内时绑定任务。无法证明来源时由用户手动选择已完成下载。持久保存 downloadId，完成后传入实际路径。中断记录错误并支持重试，任务排队且记录限量。

助手：只接收插件页面/后台指令，使用 7-Zip 列表识别真实格式和路径，再完整校验密码，检查剩余空间，在目的地隐藏临时目录解压。拒绝绝对路径、..、链接、Windows 特殊路径及已有目标。解压成功再整体重命名，原下载包保留，包内 EXE 不运行。图片由浏览器获取，单张最多5MB、合计24MB，一次消息传入助手；失败明确列出，文字始终可保存。密码只保存在插件本地存储，不进入任务日志或介绍。

默认分类根：E:\1_Game\some games，类型 ACT/ADV/GAL/RPG/SLG；未知类型拒绝自动归档。设置可更改路径、密码、7-Zip 程序路径。目标目录存在时拒绝覆盖。

验收：分类标题、PC 多候选、下载串包、归档路径穿越、密码错误、重复目标、真实加密自解压包、Native Messaging 编解码和插件页面加载。实际已登录云盘操作需要安装后验证。

安装：交付插件目录、助手源码及生成注册文件的安装器。安装器仅注册当前用户 Edge NativeMessagingHosts 指向本项目；不改变现有登录配置。插件装载需用户在 edge://extensions 开启开发者模式并加载目录。
