# IDM 自动归档接入

用户已授权接入 IDM 下载目录及成功后删除对应源包。目录为 D:\8_Temporary files\IDM\programs；范围仅本任务的压缩包，不处理整个IDM目录。

沿用网页勾选PC并点击工具栏下载。点击前 Native 助手保存该目录文件和 IDM 记录的基线，浏览器观察此专用标签的下载URL。插件每30秒检查：只考虑新文件及IDM重名后缀；须与新增/变化的IDM记录URL、完成状态、字节数一致。多候选停止。旧文件仅允许用户在任务页明确关联。

成功候选传给既有归档助手；提取后检查每个成员的存在、尺寸，并生成SHA256验证记录。介绍不完整、解压失败、目标冲突时保留源包。成功发布最终目录后，以独占读取/删除句柄再核对源包身份和SHA256，只删除这个文件；删除失败报告保留，不绕过权限。

IDM任务不再依赖Edge下载完成事件。Native按需检查，不常驻运行。设置默认IDM模式及上述目录，可切换回浏览器模式。浏览器重启后使用持久watch令牌恢复等待；已开始归档的任务提示检查后重试。

IDM注册字段只读：数字任务键的Url0、Status、FileSize、Downloaded；不读取Cookie/密码/代理等字段。仅持久化URL摘要，不写签名地址。字段格式不符合已验证布局或无法观察来源URL时不猜测，任务提示手动关联。

验证：新旧文件隔离、IDM后缀、多候选、URL与字节匹配、未完成拒绝、令牌恢复、错误密码、目标已存在、图片失败保留、仅删除成功源包、真实消息协议与隔离Edge加载。
